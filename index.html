Final Project Content

The purpose of the final project is for students to create an interactive and responsive web application that advertises the College of Information Technology (CIT) by focusing on four key professional engagement areas: Software Development, Cybersecurity, Networking, and Data Management. The application is intended to serve as a live poster animation that helps prospective students explore career opportunities in these fields and gain insight into the degree programs associated with them. Through an engaging and interactive interface, users can click on quadrants representing each area to access detailed information about career opportunities, job roles, and degree offerings. The application is required to be fully responsive, ensuring it renders well across different screen sizes, from small mobile devices to large desktop displays. The project must incorporate Purdue's branding colors and utilize interactive features like modals and dropdowns to present career-related information in an accessible and dynamic way. In essence, the project is an interactive tool designed to help students discover career pathways in CIT while showcasing the technical skills and knowledge learned throughout the course. The application should not only be visually appealing but also provide a professional, informative user experience.
