Final Project Content: Intent

The project involves creating a live poster animation for CIT, advertising the CIT's four areas of professional engagement:

  • Software Development
  • Cybersecurity
  • Networking
  • Data Management

The goal is to create a visually appealing, interactive, and responsive web app that helps students explore career opportunities in these areas. The landing page will display these areas in quadrants, and clicking on each quadrant will provide more details about the associated career pathways.

Software Development
Software Development focuses on creating applications. Career opportunities include Web Developer, Mobile App Developer, and more. Degree: Software Development.
Cybersecurity
Cybersecurity professionals protect information and systems. Career opportunities include Security Analyst, Penetration Tester, and more. Degree: Cybersecurity.
Networking
Networking involves the design, implementation, and management of networks. Career opportunities include Network Engineer, Network Administrator, and more. Degree: Networking.
Data Management
Data Management focuses on organizing, storing, and analyzing data. Career opportunities include Data Analyst, Data Scientist, and more. Degree: Data Management.
